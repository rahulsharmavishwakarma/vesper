For this 413-second recording, both delivery modes therefore use cache-aware native streaming. The model-level limit is approximately 400 seconds for direct offline execution, not an application recording cutoff.

## Research boundaries and reproduction

[Stateful Conformer](https://arxiv.org/abs/2312.17279) motivates model-compatible context and activation reuse; the exact pinned runtime implements those operations. This work changes public-API configuration and application dispatch only. It adds no native attention kernel, decoder algorithm, quantization format, trained checkpoint or self-training loop. [ADR-0012](../../docs/adrs/0012-adapter-registry-and-reviewed-personalization.md) separates those boundaries and links the prefix-caching/personalization research. [Cleanup screening](../cleanup/README.md) records the separate two-pass prefix result; its 56% warm reduction is not a Cohere/ASR or end-to-end speedup.

Prepare the public corpus using the [ASR reproduction instructions](README.md), retain the listed sample IDs/hashes, and append an identical copy of the second MUCS sample with a distinct `-after-long-reset` ID after the natural lecture. Build `transcribe-eval` in release mode. Run once with `--model nvidia/nemotron-3.5-asr-streaming-0.6b --language hi --streaming --realtime --chunk-ms 20`, then without the three streaming flags on the same manifest. Use the verified CPU-native package and an environment recording the actual four-thread graph setting. For the Cohere suite select `--model CohereLabs/cohere-transcribe-03-2026 --language en --cleanup` and preserve the source-versus-synthetic distinction in its manifest. See the JSON artifact for the exact envelopes and source snapshots; uncommitted source digests must be replaced when reproducing another tree.

Aligned word-emission/endpoint latency, actual microphone/UI behavior, queue occupancy/drop telemetry, thermal/power behavior, representative edge hardware, broad personal-vocabulary quality and anti-context evaluation remain unmeasured. Explicit push/cancel failures are preserved; lack of an error is not a separate queue-drop counter. New Cohere residency would change model lifetimes and requires its own concrete approval before implementation.
