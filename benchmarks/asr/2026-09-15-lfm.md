## Measurement envelope

Apple M5 Pro, 18 logical CPUs, 64 GiB RAM, macOS 26.6.2 (25G83), AC/automatic power mode, eight inference threads. LFM2.5-Audio-1.5B Q4_0 backbone/projector; `llama-cpp-2 = 0.1.156`, bundled llama.cpp `e79e4bf660e19f2ad851e06c6913f7a8c5852621`, mtmd enabled. Explicit CPU model devices, projector and context operations. Fresh 2048-token context per segment, 512-token output ceiling, greedy sampling, one-second low-energy boundary search, zero overlap. Exact revisions, artifact hashes and source snapshots are in the JSON report.

`asrMs` measures the completed-audio inference call, including model verification/loading on the first request, excluding file decoding, capture, IPC and UI. Cold means new model ownership; the OS file cache was not evicted. Resident requests reuse weights, not utterance state. Stage evidence reports frontend, context creation, combined audio encoding/LM prefill, and generation. `modelLoadUs` describes the retained instance's constructor time, not a repeated charge on each warm call.

Peak RSS is for the entire evaluator process. The first resource probe was blocked by macOS sandbox restrictions; its repeated run includes working RSS measurement. No physical microphone, online emission/endpoint latency, power consumption, thermal trajectory, or mobile device was measured. Background OS activity was not controlled; latency variance remains visible.

## Quality and negative findings

Meaning errors remain. One clip changed the reference's “nineteen of the injured” into wording about 1998 and being in charge; an Indian personal name was misspelled. Negations in the tested treasure-map sentence survived. The shifted repetition fixture added one extra “Sentence.” near a boundary. No universal number/name/meaning-preservation claim follows from these tests.

Longer segments were tested before retaining 10 seconds:

| Trial | Original 16-clip WER | Four boundary fixtures | Decision |
| --- | --- | --- | --- |
| 20 seconds | 8.33% | ASR 4/4; cleanup rejected 2/4; corpus WER 11.45% | Better short-clip score, but did not resolve repeated-speech/two-stage concerns; retained as an experiment |
| 30 seconds | Not rerun; all original clips are under 20 seconds | ASR returned EOS on 4/4, but omitted a whole repeated sentence; corpus WER 33.73%; cleanup rejected 2/4 | Rejected |

Every rejected cleanup retained raw text. Native EOS proves decoder termination, not that every spoken word was recognized. The fixed 10-second policy was retained for the requested two-stage path. It is an engineering bound, not an official checkpoint restriction. No changes to downloaded weights, kernels, training or runtime revisions were made.

## Reproduction and checks

Prepare FLEURS English using [README.md](README.md). The original screen uses `--count 16`; prepare `--count 32` and exclude the first 16 IDs for the reserved manifest. The report embeds all manifests and their audio hashes. The 175-second fixture preserves the baseline WAV format and repeats its data chunk 20 times, updating RIFF/data lengths and any fact sample count.

```sh
. ./scripts/dev-env.sh
cargo build --release --locked -p transcribe-eval
/usr/bin/time -l target/release/transcribe-eval run \
  MANIFEST.json CORPUS_ROOT models/downloads ENVIRONMENT.json OUTPUT.json \
  --model LiquidAI/LFM2.5-Audio-1.5B --language en
```

Add `--cleanup` for the boundary pipeline cases. Never run build/test jobs concurrently with timed evaluation. The installed-model contract test described in [LFM support](../../docs/lfm-audio.md) checks A→B→A, cancellation/reset, output exhaustion, missing projector, sample rate, silence, unload/reload, rejected streaming and shared LFM/Qwen initialization. The recorded cancellation signal was sent at 50 ms and returned at 227.5 ms from request start; audio evaluation cannot be interrupted immediately. Generic segmentation tests verify complete non-overlapping coverage and discard partial prefixes on failure/cancellation.
